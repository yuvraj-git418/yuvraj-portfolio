# Yuvraj Singh — Developer Portfolio

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current footer year

## Run locally
1. Extract the ZIP file.
2. Open the `yuvraj_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Check that your phone number, email, LinkedIn, GitHub, project links and certificate links are correct.
- Add screenshots or live-demo links for your projects if available.
- If you want a downloadable resume button, place your resume PDF in this folder and link it from `index.html`.
